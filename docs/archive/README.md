# 历史文档归档

这里保存已经收口的阶段材料，方便追溯设计、实现和验收过程。归档内容可能包含当时有效、现在已经过期的任务状态、目录路径或部署结论；当前事实以 [`../README.md`](../README.md) 列出的活动文档为准。

## 2026 年第二季度

[`2026-q2/`](2026-q2/) 包含：

- `frontend-replica/`、`refactor/`：早期视觉审计、重构计划和结果；
- `product-completion/`、`feature-audit/`、`feature-implementation/`、`bug-bash/`：产品补全与 QA 阶段记录；
- `demo-data/`、`demo-media/`：演示数据与媒体生成材料；
- `codex/`、`project_research_report/`：历史提示词与研究报告输入；
- `competition-pitch.md`、`competition-tech-figure-plan.md`、`hydration-audit.md`：已经收口的专题文档。

## 冻结规则

- 归档目录只读，不再承担当前状态、任务分派或发布验收职责。
- 历史脚本如需再次运行，输出必须写入 `artifacts/`；不得覆盖归档报告。
- 若归档结论与代码或活动文档冲突，以代码及活动文档为准。
- 需要恢复历史工作流时，应先在活动文档中登记新任务，再建立新的工作目录。
