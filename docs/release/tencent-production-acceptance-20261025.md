## 故障与修复

1. 原部署没有完成网站容器、域名和 HTTPS 切换。已启动 Next.js、FastAPI、MySQL 8.4 与 Caddy，补充腾讯云 TCP 443，并完成阿里云解析变更。
2. 后端模板的 `PORT=8000` 进入 Web 私有环境，覆盖 Next.js 默认端口，导致 3000 端口健康检查失败。已将 Web 环境改为 3000，并在 Compose 显式固定 `PORT: "3000"`；后端仍使用 8000。
3. 原数据库配置未能取回，旧服务器 SSH 超时；不能据此断言原数据已丢失。已按用户授权初始化新库，没有清理旧服务器、旧数据库或旧 Blob 对象。
4. Vivo 实际调用返回模型无权限，百炼返回 `Arrearage`。按用户选择设置 `AI_SERVICE_UNAVAILABLE=1`，页面明确提示；AI 生成请求在鉴权与作用域检查后返回结构化 503。
5. Docker Desktop 无法启动，改用本机现有 Ubuntu WSL 中的 Linux Docker 构建并传送镜像；腾讯云服务器没有执行应用构建，原 Docker Desktop 数据未重置。
6. 构建检查发现严重依赖公告，已更新为 Next.js 16.4.3、sharp 0.35.5。其他依赖告警未在本次全部消除，不代表全面安全审计通过。
