## 修复行为

- 新建儿童必须明确选择男／女，非法月龄和缺失性别在写入之前拒绝。原有性别不猜测改写，合法 0–216 月范围保持兼容。
- 注册同步提交锁防止连续提交。建档草稿按机构和用户隔离，相同资料重试使用原 requestId；恢复草稿后仍须重新确认三项同意。
- 实际 Chrome 连续切换三角色后曾出现家长 Next Link 建档跳登录、同 Cookie 整页导航却成功的问题。身份变化现在使用经角色与同源校验的整页导航；RSC／预取拒绝不删除可能已经更新的会话，私有响应明确不缓存。未知建档结果使用中文恢复提示，不将网络丢回执误写为确定创建失败。
- 会诊请求代际隔离，旧请求不得清理新请求取消句柄。LF／CRLF 和跨字节流事件正确解析；取消、离开页面、切换儿童不触发备用生成或后续保存。已发付费请求不能由本地取消推断退费。
- 录音权限迟到、关闭、卸载及初始化／转换／ASR 异常均清理当前会话，旧回调不得继续提交或覆盖新结果。浏览器原生识别与服务器 ASR 来源分开。
- 课程状态失败按有限退避读取原 job；恢复联网、返回可见页和手动刷新不创建新收费任务。课程月龄按台北业务日期计算，非法生日不能被当作新生儿。
- 绘本新增独立重试保存，保留原 storyId、完整正文和来源签名。未知结果先精确读回；只允许同一生成版本的媒体单调补齐，禁止正文冲突和已完成媒体回退。普通打开和刷新仍只读。
- Chrome追加实测发现保存同步更新Context会中断尚未返回的媒体轮询，原逻辑退出后没有恢复入口。现明确暂停并保留原书，提供需费用确认的媒体恢复；读取未完成旧书不自动发起生成，旧请求不能清除新请求句柄，结果未知的已收费任务不自动重发。
